角色头部与脸型绘制：零基础角色篇，不同人设面部特征刻画技巧

零基础画角色，最容易卡在头部和脸型。很多人一上来就抠眼睛、描头发，结果比例歪了、气质散了。头部绘制的入门心法可以概括为：先搭头骨框架，再定脸型轮廓，后用五官和发型刻画人设。顺序对了，零基础也能画出稳定、有辨识度的角色脸。

一、先搭框架：把头部当成一个球加一个楔形

画头第一步不是画脸，而是建立立体框架。正面看，头部可以理解为一个球体加下半部的楔形，球体定颅顶和额头，楔形定颧骨到下巴。先画一个圆，再在圆下方接出下巴的走向，用十字线定中轴和眼位线。眼位线通常在头部高度的中间或略低，零基础最容易把眼睛画太高，导致角色显老或比例怪异。侧面看，头部是一个椭圆加前凸的面部楔形，耳朵位于眼位线到鼻底之间。四分之三侧面是入门重点，先定中轴弧线，再定鼻尖、唇珠和下巴的转折，保持左右眼在一条透视弧线上。

框架阶段只用轻线，不要急着画细节。每次画头先花一分钟确认：颅顶够不够、下巴长短、眼位高低、脸朝向是否清楚。框架稳了，后面才不返工。

二、脸型分类：不同轮廓对应不同人设

脸型是角色气质的第一信号。常见入门脸型有五类：圆脸轮廓柔和，下巴短而圆，适合可爱、亲和、少年感角色；鹅蛋脸线条流畅，颧骨与下颌过渡自然，适合标准主角和温和型人设；瓜子脸下巴尖、下颌收得快，适合清冷、敏捷、女性化角色；方脸下颌角明显、下巴平，适合硬朗、成熟、力量型角色；长脸纵向拉长、五官间距大，适合沉稳、冷峻或智者型角色。

画脸型不要只画外轮廓，要同时想骨骼：颧骨宽不宽、下颌角高不高、下巴是尖是方。零基础可以用“三庭”辅助：发际线到眉、眉到鼻底、鼻底到下巴，三段比例决定脸的长短。调整三庭比例，就能在同一张脸上做出年龄感和气质差异。

三、五官刻画：位置比形状更重要

零基础常犯的错是眼睛画得精细，位置却不对。五官刻画先定位置，再定形状。眼睛在眼位线上，两眼间距约一只眼宽；鼻子在面部中轴，鼻底约在眉到下巴的中间；嘴巴在鼻底到下巴的上三分之一处；耳朵上沿约与眉齐，下沿约与鼻底齐。侧面和四分之三侧面要按透视调整，远侧眼睛变窄，鼻梁前凸，嘴巴沿中轴弧线偏移。

不同人设的五官重点不同。少年角色眼睛偏大、眼距略宽、鼻梁低、下巴短；成熟角色眼型偏长、鼻梁挺、下颌明确；可爱角色五官集中、脸颊饱满、嘴巴小；冷峻角色眉眼距离近、眼型细长、唇线平。五官不必每个都精细，抓住两三个特征放大，辨识度就出来了。

四、发型与表情：让人设活起来

发型是头部轮廓的一部分，不是最后才加的装饰。画头发先分组：前发、侧发、后发，再定发际线和发量走向。发型要包住头骨，不能像贴纸一样浮在脸上。不同人设的发型要有剪影差异：蓬松、服帖、束发、碎发，远看就能区分。

表情刻画从眉毛、眼睛和嘴巴三处联动入手。开心时眉毛上扬、眼睛弯、嘴角上提；生气时眉压低、眼型收紧、嘴角下压；惊讶时眉高挑、眼睛睁大、嘴巴张开。零基础先练三到五种基础表情，再练同一角色的表情变化，保证换表情不换脸。

五、实战流程与避坑

建议流程：轻线画球和楔形 → 定十字线和三庭 → 勾脸型轮廓 → 定五官位置 → 细化眼鼻嘴 → 加发型分组 → 检查剪影和比例。常见坑包括：眼睛画太高、下巴过尖或过平、左右脸不对称、头发不包头骨、五官精细但位置全错。每次画完把图缩小看剪影，能认出角色气质，说明头部和脸型就立住了。

角色头部绘制的心法是：框架定立体，脸型定气质，五官定辨识，发型定剪影。零基础不用追求一次画精，先求比例稳、特征清，再逐步加细节。画多了会发现，脸型一变，人设就换了一个人。
